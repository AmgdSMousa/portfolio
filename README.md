# Amged Sayed - Portfolio Website

Official portfolio website of **Amged Sayed** — Full-Stack Web Developer, Cloud Infrastructure Specialist, and Digital Marketer.

## 🛠️ Built With

- **React 19**
- **Vite**
- **Tailwind CSS v4**
- **Lucide Icons**

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
